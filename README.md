# 내전서버 관리

친구들끼리 쓰는 롤 내전 운영 사이트입니다.

## 포함 기능

- 내전 참가자 관리
- 내전 결과 입력 및 승패 랭킹
- 기존 경매 프로그램 통합
- 기존 티어표 프로그램 통합

## 배포

GitHub Pages에 그대로 올리면 됩니다.

주요 파일:

- `index.html`
- `styles.css`
- `app.js`
- `auction/`
- `tier/`

## 로컬 테스트

```powershell
npm start
```

로컬 서버 주소:

```text
http://localhost:5177
```

## 메모

- Riot API 전적검색 기능은 제거했습니다.
- 사용자 설정 게임은 공식 전적 API에서 안정적으로 내려오지 않기 때문에, 내전은 사이트 안에서 직접 기록하는 방식으로 관리합니다.
- 저장된 참가자와 경기 기록은 브라우저 localStorage에 저장됩니다.
